# Ícones / retratos dos personagens de MK

O card de luta tenta carregar, nesta ordem:

1. **`<personagem>.png`** — seu retrato (o que você quer usar). Recomendo PNG ~80×80 a 160×160, de preferência com o rosto centralizado em cima.
2. `<personagem>.svg` — ícone-símbolo que eu gerei (fallback automático).
3. Monograma (as iniciais) — se faltar os dois.

Ou seja: **é só jogar os PNG aqui nesta pasta com o nome exato abaixo** e pronto.
